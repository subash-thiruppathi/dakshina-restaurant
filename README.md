# 🪔 DAKSHINA — Royal South Indian Gastronomy & Bar

An elegant, appetite-inducing fine-dining web application celebrating the royal culinary heritage of South India (Chettinad, Malabar, Mysore & Coromandel Coast).

Designed with a luxury dark temple aesthetic, rich storytelling, one-click sensory pairings, an interactive feast ordering bag, and a traditional banana leaf table reservation system.

---

## ✨ Key Features

- **Sensory Food Photography & Aromatics**: High-impact appetite appeal with golden A2 ghee roast dosas, sizzling Tellicherry pepper mutton chukka, raw mango king prawn curries, and clay-pot Thalassery dum biryani.
- **Appetite Boosters & One-Click Pairings**: Each dish recommends a traditional soulmate pairing (e.g. Kumbakonam brass filter coffee, flaky Malabar porottas, digestive rasam).
- **Interactive Royal Feast Bag (Cart Drawer)**:
  - Customization for spice intensity (*Gentle & Mild*, *Authentic Dakshin Tradition*, *Fiery Karaikudi Heat 🌶️*) and complimentary extra ghee showers.
  - Impulse craving add-ons before checkout.
  - Thermal insulated delivery vs. curbside valet pickup toggle.
  - Indian Rupee (₹ / INR) pricing with 5% restaurant GST calculation.
- **Simulated Checkout Flow**: Full guest information input, Indian payment options (UPI, NetBanking, Pay on Hand-off), and live hearth dispatch tracking (`DAK-XXXX`).
- **Banana Leaf Table Reservation System**: Booking for *Royal Banana Leaf Feast Seating*, *Chettinad Teakwood Courtyard*, or *Chef's Tiffin Counter*.
- **The Sacred Hearth Story**: Chef Meenakshi Sundaram's 3-star lineage, stone-ground batter philosophy, and single-estate Western Ghats spices.
- **Accolades & Reviews**: Acclaim from dining critics and epicurean diners.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm (v9+)

### Installation

```bash
# Clone the repository
git clone <your-repository-url>

# Navigate to project directory
cd aurelia-restaurant

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be live at `http://localhost:5173/`.

### Production Build

```bash
# Create optimized production build
npm run build

# Preview production build locally
npm run preview
```
